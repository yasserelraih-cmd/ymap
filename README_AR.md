# YMAP — دليل التشغيل (الإصدار 0.2.0: الخطوتان 1.0 و1.1)

الناتج المطلوب: تطبيق YMAP يفتح على جوالك بالعربية، فيه الوضع الليلي والإنجليزية، ويتكيف مع التابلت والآيباد.

## أ) التثبيت (مرة واحدة فقط)

1. ثبّت **VS Code** من: https://code.visualstudio.com
2. افتح VS Code ← أيقونة الإضافات (Extensions) ← ابحث عن **Flutter** ← Install.
3. اضغط `Ctrl+Shift+P` (ويندوز) أو `Cmd+Shift+P` (ماك) ← اكتب `Flutter: New Project` ← سيطلب تحميل Flutter SDK ← اختر **Download SDK** واختر مجلداً مثل `C:\src` أو `~/development`.
   - يجب أن يكون الإصدار **Flutter 3.50 أو أحدث**.
4. **لجوال أندرويد:** ثبّت **Android Studio** من https://developer.android.com/studio وافتحه مرة واحدة ليكمل تحميل Android SDK.
5. **لآيفون أو آيباد:** تحتاج جهاز **ماك** وتثبيت **Xcode** من App Store.
6. افتح الطرفية في VS Code (Terminal ← New Terminal) واكتب:
   ```
   flutter doctor
   ```
   كل سطر بعلامة ✓ جاهز. أرسل لي أي سطر عليه ✗ وأحلّه معك.

## ب) تشغيل المشروع

1. فك ضغط `ymap.zip` في مجلد مثل `Documents/YMAP`.
2. في VS Code: File ← Open Folder ← اختر مجلد `ymap`.
3. في الطرفية:
   ```
   flutter pub get
   ```
4. وصّل جوالك بالكابل:
   - **أندرويد:** الإعدادات ← حول الهاتف ← اضغط «رقم الإصدار» 7 مرات ← خيارات المطوّر ← فعّل «تصحيح USB».
   - **آيفون:** افتح `ios/Runner.xcworkspace` في Xcode ← Signing & Capabilities ← اختر حساب Apple ID الخاص بك ← ثم على الجوال: الإعدادات ← عام ← إدارة VPN والجهاز ← وثّق المطوّر.
5. شغّل التطبيق:
   ```
   flutter run
   ```
